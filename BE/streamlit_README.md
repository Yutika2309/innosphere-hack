# Streamlit Output Dashboard

Standalone Streamlit UI for the lending simulation.

The dashboard does **not** import or call simulation runtime code. It only reads CSV files generated under the `output/` directory, or CSV files uploaded from the sidebar.

It now supports the agentic multi-agent simulation output model where public/private separation is represented by a row-level `visibility` column.

---

## Purpose

Use the dashboard to inspect:

- simulation progression by timestep,
- Deutsche Bank wins, competitor wins and drop-offs,
- customer pivot points and loss reasons,
- public vs private agent action rows,
- public information available to agents in the next timestep,
- optional debug view of private summaries,
- improvement projection checkboxes,
- raw CSV previews.

---

## Files expected

The dashboard can read these files from `output/`.

### Core reporting files

```text
conversion_metrics.csv
customer_lifecycle.csv
db_loss_analysis.csv
db_recommendations.csv
scenario_comparison.csv
```

### Agentic action/event files

```text
consumer_actions.csv
bank_actions.csv
marketing_actions.csv
world_news.csv
funnel_events.csv
bank_offers.csv
customer_feedback.csv
```

These files should include a `visibility` column where applicable:

```text
visibility = public | private
```

### Context files

```text
public_information.csv
private_summaries.csv
```

- `public_information.csv` contains public-only rows consolidated after each timestep.
- `private_summaries.csv` contains actor-specific summaries generated from private rows.

---

## Visibility model

The dashboard supports three visibility views from the sidebar:

```text
Public only
Private only
All rows
```

Recommended normal replay mode:

```text
Public only
```

Use `Private only` or `All rows` only for debugging the context-separation logic.

World news should always appear as:

```text
visibility = public
```

---

## Dashboard tabs

### Simulation progression

Shows funnel and lifecycle progression over time.

### Agent actions

Shows combined agent rows from:

```text
consumer_actions.csv
bank_actions.csv
marketing_actions.csv
world_news.csv
funnel_events.csv
bank_offers.csv
customer_feedback.csv
```

The rows shown here respect the sidebar visibility filter.

### Public context

Shows `public_information.csv`, which is the public context available to all agents in the next timestep.

If debug mode is enabled, this tab also shows `private_summaries.csv`.

### Customer pivot points

Shows Deutsche Bank loss analysis and competitor destinations where available.

### Improvement checkboxes

Lets you tick improvement options and see a UI-side projection. This is not authoritative simulation output. Use `scenario_comparison.csv` for scenario results generated by the simulation.

### Reviews / feedback

Shows customer feedback rows up to the selected timestep, filtered by visibility.

### Raw CSV preview

Shows loaded files and lets you preview individual CSVs. Private summaries are hidden unless debug mode is enabled.

## Run

From your project root:

```bash
pip install -r streamlit_requirements.txt
streamlit run streamlit_dashboard.py
```

By default, it reads from:

```text
output/
```

You can also upload CSVs from the sidebar.

---

## Notes

- The dashboard is independent of the simulation runtime.
- It does not execute agents.
- It does not mutate output CSVs.
- It is intended for replay, inspection and debugging.
- Private rows and private summaries should be used only for debugging context separation.
